# Objetos do Sistema

## Dor declarada

Informacao fornecida pelo cliente. Nao deve ser tratada como fato validado sem evidencias.

Campos principais:

- descricao
- area impactada
- recorrencia
- impacto percebido
- tentativa anterior
- urgencia
- evidencia declarada

## Cenario macro

Hipotese de mudanca tecnologica ou de mercado.

Campos principais:

- titulo
- hipotese "E se?"
- velocidade da mudanca
- areas afetadas
- risco de obsolescencia
- oportunidade
- resposta recomendada

## Achado simulado

Achado demonstrativo usado apenas para a demo.

Campos principais:

- dimensao
- descricao
- risco
- evidencia necessaria em auditoria real
- metodo de validacao
- prioridade
- autorizacao necessaria
- status

## Acao recomendada

Uma acao so entra no plano se tiver origem, impacto, artefato, responsavel sugerido e criterio de aceite.

Campos principais:

- origem
- objetivo
- prioridade
- esforco
- impacto esperado
- responsavel sugerido
- artefato
- criterio de aceite
- dependencia
- status

## Artefato Codex

Entrega versionavel e revisavel.

Exemplos:

- playbook
- checklist
- politica
- log de decisao
- backlog
- relatorio executivo
